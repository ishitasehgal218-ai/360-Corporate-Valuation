# 360° Corporate Valuation — AI Investment Intelligence

An ML-powered investment analysis platform that generates 
comprehensive financial reports for any public company.

## Features
- Real-time stock data via yfinance
- 14+ engineered technical & fundamental features  
- Random Forest health classifier
- Gradient Boosting valuation regressor
- Isolation Forest anomaly detection
- AI-generated investment report via GPT-4
- Interactive Streamlit dashboard

## Tech Stack
Python, Scikit-learn, Streamlit, Plotly, yfinance, OpenAI API

## Run Locally
pip install -r requirements.txt
streamlit run app.py
